创建一个个人插件市场主要包含三个步骤：建立 Git 仓库、创建目录结构、编写配置文件。以下是详细的操作指南：

### 1. 初始化插件市场仓库

首先创建一个新的文件夹并初始化为 Git 仓库。这个仓库将作为你的个人插件市场。

```bash
mkdir my-codebuddy-market
cd my-codebuddy-market
git init
```

### 2. 创建必要的文件结构

CodeBuddy 识别插件市场的关键在于 `.codebuddy-plugin` 目录下的 `marketplace.json` 文件。

请按以下结构创建文件：

```text
my-codebuddy-market/
├── .codebuddy-plugin/
│   └── marketplace.json      # 核心配置文件
└── plugins/                  # (可选) 如果你直接在这个仓库放插件源码
    └── my-awesome-plugin/
        └── .codebuddy-plugin/
            └── plugin.json
```

### 3. 编写 marketplace.json

在 `.codebuddy-plugin/marketplace.json` 中定义市场信息和包含的插件。

**文件内容示例：**

```json
{
  "name": "my-personal-market",
  "owner": {
    "name": "Your Name",
    "email": "your-email@example.com"
  },
  "description": "我的个人 CodeBuddy 插件收藏",
  "plugins": [
    {
      "name": "my-tool",
      "description": "一个非常有用的工具插件",
      "version": "1.0.0",
      "source": {
        "source": "github",
        "repo": "username/my-tool-repo"
      }
    },
    {
      "name": "local-helper",
      "description": "本地辅助脚本",
      "source": "./plugins/local-helper"
    }
  ]
}
```

#### 关键字段说明：
- **name**: 市场的唯一标识符（不含空格的 kebab-case）。
- **plugins**: 插件列表数组。
  - **source**: 插件来源。
    - 引用 GitHub 仓库：`{ "source": "github", "repo": "owner/repo" }`
    - 引用当前仓库的子目录：直接写路径字符串，如 `"./plugins/my-plugin"`
    - 引用其他 Git 地址：`{ "source": "git", "url": "https://..." }`

### 4. 发布与使用

1.  **提交并推送**代码到你的 Git 托管平台（如 GitHub/GitLab）。
2.  **在 CodeBuddy 中添加市场**：

    使用以下命令将你的新市场添加到 CodeBuddy：

    ```bash
    # 如果是 GitHub 仓库
    /plugin marketplace add github_username/repo_name

    # 如果是其他 Git 仓库 URL
    /plugin marketplace add https://your-git-server.com/market.git
    ```

添加成功后，你就可以使用 `/plugin list` 查看并安装你自己市场中的插件了。
