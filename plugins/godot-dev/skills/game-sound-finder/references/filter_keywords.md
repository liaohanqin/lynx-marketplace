# 筛选逻辑参考

## 时长筛选

| 用户描述 | 对应范围 |
|---------|---------|
| 短音效 | 3 秒以内 |
| 中等 | 3~30 秒 |
| 背景音乐 / 循环 | 1 分钟以上 |
| 具体描述（"不超过5秒"）| 直接对应 |

## 风格关键词对照（中→英）

| 中文需求 | 英文搜索词 |
|---------|-----------|
| 按钮点击 | button click, ui click |
| 通知提示 | notification, alert, ding |
| 自然环境 | nature, rain, wind, birds |
| 游戏音效 | game, arcade, coin, jump |
| 太空/宇宙氛围 | space ambient, cosmic, void |
| 黑暗/恐怖 | dark ambient, horror, ominous |
| 史诗/磅礴 | epic, cinematic, orchestral |
| 轻松/休闲 | casual, upbeat, lofi |
