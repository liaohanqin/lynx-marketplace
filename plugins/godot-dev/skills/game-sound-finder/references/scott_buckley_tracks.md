## 下载方式

1. WebFetch 访问具体曲目页：`https://www.scottbuckley.com.au/library/TRACKNAME/`
2. 页面中找到 `[MP3 (Full Mix)](直接URL)` 链接
3. 用 curl 直接下载：
   ```bash
   curl -L --output "sounds/FILENAME.mp3" \
     "https://www.scottbuckley.com.au/library/wp-content/uploads/YYYY/MM/TRACKNAME.mp3"
   ```
