# 支持的音效网站（按优先级）

1. **Pixabay**（首选）：免费商用，无版权限制
   - 音效：`https://pixabay.com/sound-effects/search/KEYWORD/`
   - 音乐：`https://pixabay.com/music/search/KEYWORD/`
2. **Scott Buckley**（氛围/史诗备选）：CC BY 4.0，需注明来源
   - `https://www.scottbuckley.com.au/library/`
3. **Chosic**：免费，大多 CC 授权
   - `https://www.chosic.com/free-music/`
4. **Free Music Archive**：免费，多种 CC 授权
   - `https://freemusicarchive.org/genre/Ambient`
